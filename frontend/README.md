# Campus Mart - Frontend Applications

This directory contains the client-facing user interfaces for **Campus Mart**:

---

## 📱 Client Packages

| Client | Directory | Technology | Target Platforms |
| :--- | :--- | :--- | :--- |
| **Flutter Mobile App** | [`flutter/`](./flutter/) | Flutter 3.x, Dart 3.x, Material 3 | Android, iOS, Desktop |
| **Web Application** | [`web/`](./web/) | React 19, Vite 8, TypeScript, Tailwind CSS | Modern Web Browsers |

---

## 🚀 Running the Clients

### 1. Web Application (`web/`)
```bash
cd frontend/web
npm install
npm run dev
# Serves on http://localhost:3000
```

### 2. Flutter Mobile Application (`flutter/`)
```bash
cd frontend/flutter
flutter pub get
flutter run
# Launches on connected device or emulator
```
